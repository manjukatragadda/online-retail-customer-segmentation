# Customer Segmentation using Clustering

## Project Overview

This project performs customer segmentation using the Online Retail dataset using RFM analysis and clustering techniques.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Algorithms Used

- K-Means Clustering
- DBSCAN

## Features

- Data Cleaning
- RFM Analysis
- PCA Visualization
- Customer Segmentation
- Business Insights

## Dataset

Online Retail Dataset:
https://www.kaggle.com/datasets/vijayuv/onlineretail
